# Module 0.5 — Development Environment

## 🎯 Concepts Covered
- Workspace Configuration (VS Code, Terminal)
- Note-Taking & Documentation (Notion / Obsidian)
- Git & GitHub Fundamentals
- Personal Security Hygiene (Password Managers & 2FA)

---

## 📌 Detailed Breakdown

### 1. Documentation Tools
- Cyber Security requires structured knowledge retention rather than memorization. 
- Building a Personal Wiki (using Notion/Obsidian) helps in fast retrieval of commands and methodologies.

### 2. Version Control (Git & GitHub)
- **Git:** Tracks code modifications and script versions locally.
- **GitHub:** Acts as a centralized portfolio for sharing lab setups, automation scripts, and project collaboration.

### 3. Security Hygiene
- **Password Manager:** Centralized vault for generating and storing complex, unique passwords.
- **Two-Factor Authentication (2FA):** Provides an essential secondary layer of access validation.
