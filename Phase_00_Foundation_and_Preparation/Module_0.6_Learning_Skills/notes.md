# Module 0.6 — Learning Skills

## 🎯 Concepts Covered
- Reading Official Documentation & RFCs
- Advanced Search Techniques & Error Solving
- Navigating Stack Overflow & GitHub Repositories
- Reading Release Notes & Changelogs

---

## 📌 Detailed Breakdown

### 1. Documentation Priority
- Official vendor documentation (e.g., Ubuntu, OWASP, NIST) is the authoritative source for security configurations and troubleshooting.

### 2. Search Mechanics & Debugging
- Utilizing exact-match syntax and error code quotes when querying search engines to quickly isolate solutions.
- Utilizing Stack Overflow and GitHub repository issue trackers for debugging hardware/software edge cases.

### 3. Terminal Documentation Access
- `man <command>` and `info <command>` are the built-in primary sources of documentation within Linux environments.
