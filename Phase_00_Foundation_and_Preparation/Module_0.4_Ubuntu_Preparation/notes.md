## 📌 Detailed Breakdown

### 1. Ubuntu LTS (Long Term Support)
- Released every 2 years with 5 years of guaranteed security updates and stability.
- Serves as the base workstation for security analysts and SOC operations.

### 2. ISO Verification (Integrity Check)
- Using SHA256 Checksum to ensure the downloaded ISO image is untampered and non-corrupted.

### 3. Virtual Machine Snapshots
- Creating point-in-time state restores for safe malware testing and system recovery.
