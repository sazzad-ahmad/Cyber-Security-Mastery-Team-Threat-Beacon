# Module 0.2 — Computer Fundamentals

## 🎯 Concepts Covered
- CPU, RAM, ROM, and Cache Architecture
- Storage Types (HDD vs SSD vs NVMe)
- Number Systems (Binary & Hexadecimal)
- Boot Sequence (POST & BIOS/UEFI Mechanics)

---

## 📌 Detailed Breakdown
- **CPU:** Central Processing Unit executing instructions via ALU & CU.
- **RAM:** Volatile primary memory used for running processes (crucial for RAM forensics).
- **ROM:** Non-volatile memory holding system boot firmware (BIOS/UEFI).
- **Hexadecimal:** Base-16 system used to simplify binary representations in networking and memory addresses.
- **Boot Process:** Power-On -> POST -> BIOS/UEFI -> Bootloader (GRUB) -> Kernel.
