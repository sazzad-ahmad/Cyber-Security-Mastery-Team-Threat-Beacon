# Module 1.4 — Command Line Interface (CLI) Fundamentals

## 🎯 Concepts Covered
- Terminal & Shell Mechanics
- Absolute vs Relative Pathing
- Essential Directory Navigation (`pwd`, `ls`, `cd`)
- I/O Redirection (`>`, `>>`) and Piping (`|`)

---

## 📌 Detailed Breakdown

### 1. Navigation Concepts
- **Absolute Path:** Explicit path representation starting from the root directory (`/`).
- **Relative Path:** Contextual path representation relative to the current working directory (`.`).

### 2. Redirection & Pipes
- **`>` Operator:** Redirects standard output (stdout) to a target file, overwriting existing contents.
- **`>>` Operator:** Redirects stdout by appending to the end of the file.
- **`|` (Pipe):** Chaining execution outputs by feeding standard output of one command as standard input to another.
